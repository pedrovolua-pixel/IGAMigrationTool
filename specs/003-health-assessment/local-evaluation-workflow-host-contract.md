## Admission and isolation

The new `src/server/hosts/LocalEvaluationDemo` executable starts only with `--enable-synthetic-evaluation-workflow`. It requires the explicit `IGA_SYNTHETIC_EVALUATION_DATABASE` connection and a loopback PostgreSQL18 database whose name begins `iga_synthetic_evaluation_`. No fallback database, shared-role change, server restart, HBA edit or destructive migration is permitted. Domain store admission independently enforces its connection/schema boundary. Static assets are the dedicated `src/web/evaluation` build. Existing consultant host, entry and configuration remain unchanged.

Kestrel listens only on127.0.0.1:5184. Admission checks the actual remote address and exact Host `127.0.0.1:5184` or `localhost:5184`; reject forwarded/spoofed hosts. APIs use `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, no-referrer and CSP with self-only scripts/styles/connect, no frames/objects/base and no remote assets. No CORS or raw evidence route exists. Static path resolution rejects traversal and serves only build files beneath the configured asset directory.

The configured fixture actor is server-only `synthetic-reviewer`. HTTP never accepts identity, role, qualification, conflict clearance, grant, timestamp, assignment or registry mutation. Every operation delegates current scope/category/action admission to the trusted store. Persisted current registry versions are the authority, including replay; initial seed must not replace an existing registry on restart.

## HTTP and failures

Versioned `/local-evaluation/v1` operations are GET `/workspace`, GET `/members/{memberId}`, GET `/versions/{version}`, GET `/members/{memberId}/history?afterSequence={safeInteger}` and POST `/events`. No other query parameter is admitted; only the history route accepts its one optional cursor. Each response is exactly `{schemaVersion:1,demoOnly:true,csrfToken:string|null,issue:string|null,payload:object|null,alreadyApplied:boolean|null}`. Successful payload is the exact corresponding domain DTO; issue is null. Workspace GET includes a newly minted CSRF token; other responses use null. Successful apply alone has the stored receipt and boolean alreadyApplied. Failures have null token/payload/alreadyApplied and one closed domain issue or host-only Unavailable. Serialize the full response to bounded UTF8 bytes before sending; exceeding2MiB returns metadata-only Unavailable and never partial protected JSON. The initial workspace projection includes an ASP.NET antiforgery request token minted with an ephemeral data-protection provider and dedicated HttpOnly SameSite=Strict cookie. Mutation requires same-origin exact Origin, exact `application/json`, no query parameters and valid `X-CSRF-TOKEN`. JSON parsing rejects duplicate, missing/extra keys, trailing data and nonexact enum/scalar values. Bound request256KiB and response2MiB; command text is separately bounded by the domain contract. UUIDs/digests/revisions are expectations, never authority.

Closed metadata-only failures contain schemaVersion1, demoOnly=true and a typed issue from the domain closed list, without submitted values, source/review payload or internal exception details. InvalidInput→400; Denied→403; NotFound→404; stale expectation/UUID conflict→409; source/integrity/dependency unavailable→503. HTTP method/body/origin failures cannot manufacture review outcomes or alter state. Unknown routes/methods receive equivalent generic errors. Disable built-in request, exception and Npgsql payload logging; use no default logger providers. Any explicit dependency logging contains only exception kind, no arguments, rationale, connection data, stack or payload. Client abort after submission is an unknown result, never proof of rollback.

The host owns source fixture construction matching the existing immutable sampling golden, plus fictional original conclusions and bounded opaque reference IDs. Server fixture initialization verifies canonical120 population,100 selected,40 mandatory and15/45 lower allocation against the preexisting independently generated population/sample digests. It never imports Phase1B originals or customer data. Domain owns event storage, integrity checks, current-policy transactions and canonical outcome bytes; host performs transport adaptation only.
