## Independent oracle and fixture authority

Before implementing the codec/store, a verifier other than its author writes fixed fictional terminal source/projection/score/manifest/receipt byte fixtures and literal SHA-256 goldens using a separately authored reference script. Preserve the script/source/byte digests and initial fixture commit. Never regenerate expected values from the implementation under test. Fixtures use UUID scopes and exact native schemas; they do not reuse syn-* or claim eligible One Identity source, real approvals, customer access, provider controls or acceptance.

Fixture owning source tables retain terminal run/review/coverage/scoring/maturity revisions, source-bound input commitments and current fixture authority/lifecycle revisions. They are expressly fixture records, not a mutation of AssessmentRuns. Capture and revocation share an actual persisted transaction/fence. Spies count source, metadata, each blob, raw resolver (always absent), publication/audit writes and callback emissions. Database login tests prove privileges, not just policy booleans. Test clocks and commit interruption hooks are injected trusted fixture ports only.
