# Cycle09 internal synthetic AI preview contract

Status: Settled local engineering representation, 2026-10-02, under the approved local build and Cycle09; not a production/public API, permission, persistence, report publication or renderer-deployment contract.

## Boundary and input authority

The new `SyntheticAiPreview` module references only the existing dependency-free `SyntheticAiValidation` module and framework libraries. It has no database, resolver, provider, SDK, network client, host route or customer policy. A separate test host composes fixed fictional fixtures and may write a local HTML preview for browser verification. The existing application is not connected to it. Accepted ADR content-processing isolation remains required for any future production integration.

`SyntheticAiPreviewBuilder.Build(SyntheticAiPacket? packet, SyntheticAiProposalSnapshot? proposal)` accepts only the immutable values returned by Cycle08's real factories. Their nonpublic constructors and get-only fields are the internal trusted-value boundary; arbitrary JSON or caller-authored preview values are not an input surface. Hashes/scope labels do not authenticate actors or prove real redaction. Validate complete packet/proposal UTF-8 SHA256 integrity and exact run/packet membership binding before projection. Structural/type/bounds failures return typed payload-free denial with null Snapshot; never return partial or stale display. Existing Cycle08 factories remain authoritative for closed shape, citation, declared conflict and parser validation.

Parse detached canonical JSON with depth16 and a local 4MiB per-value guard, sufficient for valid escaped Cycle08 canonical output. Do not redispatch canonical values into the original wire-size parser: default escaping can expand a valid original input. Preserve all valid existing factory values including Unicode/boundary cases. Check packet metadata agrees with canonical run/evidence/rule IDs, proposal root is the exact immutable snapshot shape and its packet/run/count agree. No source evidence configuration value, raw canonical packet, storage locator, original fake-provider response or additional executable field is displayed.

## Projection records and bytes

Public signatures/types are settled in `src/server/modules/SyntheticAiPreview/PreviewContracts.cs` before worker implementation. Snapshot has no public constructor or writable properties. Collections are immutable; copying a child record cannot mutate a previously returned snapshot. Typed Source preserves all nine fictional packet source fields. Proposals preserve proposalId, facts, inferences, assumptions, missingContext, suggestions, uncertainty and conflictingEvidenceIds. Every statement preserves text/evidenceIds/ruleIds. Existing sorted proposal/citation IDs and ordered statement/missingContext arrays remain unchanged. Zero proposals produce an empty immutable array and the same Proposed status, not a healthy finding.

Preview canonical JSON is the complete object with exactly `schemaVersion` (`synthetic-ai-preview-v1`), `status` (`Proposed`), `source`, `packetDigest`, `proposalDigest`, `proposals`, `disclaimer`. Property names are camelCase and recursively ordinal-sorted. Source runId is lowercase D UUID. Arrays preserve the validated snapshot order. Strings use default System.Text.Json escaping; no BOM/trailing newline. SHA256 lowercase hex over UTF-8 bytes gives ContentDigest. The fixed disclaimer is exactly the shared constant in PreviewContracts; it states fictional offline purpose, proposed/untrusted output, unverified cited facts and absence of action authority.

The generated preview exposes CanonicalJson/ContentDigest, Source, PacketDigest, ProposalDigest and Proposals plus fixed SchemaVersion/Status/Disclaimer. The payload digest includes every displayed field. Renderer can accept only this immutable snapshot. It checks its canonical digest and fixed schema/status/source bindings before output. Failure is typed and payload-free.

## Inert HTML contract

`SyntheticAiPreviewRenderer.Render(SyntheticAiPreviewSnapshot? snapshot)` returns PreviewRenderResult with immutable PreviewHtmlSnapshot or typed denial. HTML is a complete deterministic UTF-8 document, no BOM/trailing newline, fixed title `Synthetic AI proposal preview`, language en, viewport, one h1 and semantic source/proposal/typed-statement/missing-context/uncertainty/citation sections. Fixed Proposed/untrusted disclaimer is always visible. Proposal IDs, run and input digests identify the exact displayed value; PreviewDigest binds its canonical source. Empty result explicitly says `No proposals were returned. This does not establish healthy or complete assessment coverage.` Never synthesize a fact or omit declared uncertainty/context.

Every dynamic string is encoded using framework HTML text encoding. Dynamic text never supplies tag/attribute names, CSS, JavaScript, URL, href/src, IDs or event handlers. There is no script, form, iframe, object, SVG, image, link to an external resource, data URL, executable handler, fetch or download/review/action control. Citation IDs are text only; no evidence is resolved. Fixed skip/in-document navigation anchors may refer only to fixed literal IDs. Fixed inline CSS may support readable wrapping, visible keyboard focus, mobile/320px reflow and contrast. Content Security Policy meta is fixed `default-src 'none'; style-src 'unsafe-inline'; base-uri 'none'; form-action 'none'`; no dynamic policy input. This is a local serialized preview, not proof of production sandbox/deployed-header enforcement.

Output guard is4MiB UTF-8; exceeding it returns OutputTooLarge, not truncated content. Html/ContentDigest/PreviewDigest are immutable; ContentDigest is lowercase SHA256 over the entire HTML UTF-8. Text labels Facts/Inferences/Assumptions/Suggestions distinguish model assertions from verified facts; source/proposal disclaimer remains visible. Exact markup golden is independently authored by the HTML worker/verifier; no renderer-generated golden becomes its own oracle.

## Verification and limits

Portable tests include actual Cycle08 factories, positive/empty/conflict/hostile/Unicode inputs, wrong packet/run/content/metadata denial, immutability and deterministic full canonical/HTML bytes. Independent composition uses its own literal fake responses and primitive goldens, not implementation helpers as the expected-value oracle. Actual browser tests verify text fidelity, no injected script/event/node/network activation, source/typed categories/citations/conflict/context/empty display, keyboard skip/navigation and desktop/mobile/320px reflow; log codes/counts/digests rather than supplied strings. Protected data/real provider/production auth/publication/retention/task/CSV/score/review integration and supported Windows/screen-reader/manual acceptance remain NOT VERIFIED.
