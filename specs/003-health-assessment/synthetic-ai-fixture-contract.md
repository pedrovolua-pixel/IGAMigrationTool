# Cycle08 internal synthetic AI fixture contract

Status: Settled local engineering contract, 2026-10-02, under the approved local build; not a production AI, authorization, budget, storage or public API contract.

Authority: approved FR-HAS-30–33, AC-HAS-8, IP-HAS-007/Milestone6, TP-HAS-008 and the [AI data controls](../../docs/security/health-assessment-ai-data-controls.md). The [local build](../../plans/active/one-identity-local-pilot-build.md) explicitly calls for fake-provider packet/output validation with adversarial fixtures. ADR-0001/0002/0003/0004 remain unchanged. This contract selects internal executable fixture representations, not new product permissions or live data processing.

## Boundary

Implement a dependency-free `SyntheticAiValidation` module and portable test hosts. Only already-authorized, fictional, normalized/redacted fixture data enters the builder. Declared classification, fixed scope, IDs and digests cannot authenticate an actor or prove redaction. There is no real provider, SDK, network client, tool, secret, raw resolver, database, renderer, host route or production-policy integration. A fake provider lives in the test host and returns fixed response strings. Existing historical `synthetic-ai-disabled-v1` run locks, profiles, scoring, review, drafts and guidance remain unchanged. No output is persisted or promoted into a finding, score or recommendation.

## Packet input and value

`SyntheticAiPacketBuilder.Build(string? inputJson)` returns a typed payload-free failure or an immutable `SyntheticAiPacket`. Closed input properties, case-sensitive, are `schemaVersion`, `source`, `evidence`, `ruleIds`. Schema is `synthetic-ai-fixture-input-v1`. Source has exactly `customerId`, `projectId`, `environmentId`, `runId`, `baselineDigest`, `profileDigest`, `normalizationVersion`, `redactionVersion`, `promptVersion`. Fixed scope is `synthetic-customer`/`synthetic-project`/`synthetic-environment`; run is nonempty lowercase canonical UUID; digests are lowercase 64-hex. Versions respectively equal `fixture-normalization-v1`, `fixture-redaction-v1`, `fixture-prompt-v1`.

Each evidence record has exactly `evidenceId`, `classification`, `redactionCount`, `configurationKey`, `configurationValue`. Evidence ID is `ev-` plus lowercase 64-hex, unique within the packet; classification is `NormalizedRedactedConfiguration`; redactionCount is an integer 0–1000000. Configuration key is the fixture allowlist `scheduleEnabled` or `retryPolicy`. Configuration value is an inert string, never an instruction. There are 1–16 records. There are 1–2 unique rule IDs from `fixture-rule-schedule-v1` and `fixture-rule-conflict-v1`; their authoritative status is fictional fixture status only. Free-text/comment/script/raw fields, storage locators, policy declarations, tools and unsupported properties are rejected. These structural checks cannot establish semantic redaction or real-source authorization.

Packet canonical JSON has exactly `schemaVersion` (`synthetic-ai-fixture-packet-v1`), `status` (`SyntheticDataOnly`), `source`, `evidence`, `ruleIds`. Property names sort ordinal recursively; evidence sorts by evidenceId and rules sort ordinal. Strings use System.Text.Json default escaping; numbers are integers; arrays otherwise retain order; no BOM/newline. SHA256 lowercase hex over UTF-8 canonical JSON binds the entire packet. Packet exposes read-only `CanonicalJson`, `ContentDigest`, `RunId`, immutable `EvidenceIds`, `RuleIds`. The type has no public constructor or writable properties. Its digest grants no authority. Changing source/run/data changes the digest; equivalent property/evidence/rule ordering does not.

## Closed proposed output

`SyntheticAiProposalValidator.Validate(SyntheticAiPacket? packet, string? outputJson)` returns a typed payload-free failure or immutable `SyntheticAiProposalSnapshot`. Closed output properties are `schemaVersion` (`synthetic-ai-fixture-output-v1`), `runId`, `packetDigest`, `proposals`. Run and packet digest must exactly match the supplied packet. There are 0–16 proposals; zero is an explicit empty proposed result, never healthy evidence. Each proposal has exactly `proposalId`, `facts`, `inferences`, `assumptions`, `missingContext`, `suggestions`, `uncertainty`, `conflictingEvidenceIds`. Proposal IDs are unique `proposal-` plus two decimal digits. Facts, inferences, assumptions and suggestions are distinct arrays (0–16 entries each) of closed objects with `text`, `evidenceIds`, `ruleIds`; every statement has nonblank text, 1–16 unique packet-member evidence IDs and 1–2 unique packet-member rule IDs. At least one statement across those four arrays is required per proposal. No state/severity/approval/risk/policy/tool/fetch/execution property is allowed.

MissingContext is an ordered array of 0–16 nonblank inert strings. Uncertainty is an inert string, allowed empty when there is no declared conflict. ConflictingEvidenceIds contains 0–16 unique packet-member IDs; when nonempty it requires at least two IDs, nonblank uncertainty and at least one missingContext entry. This preserves declared conflict, but cannot detect an undeclared semantic contradiction or prove that a cited conclusion follows from evidence. No schema validator proves real-model injection resistance or factual accuracy.

Accepted snapshot canonical JSON contains `schemaVersion` (`synthetic-ai-proposal-snapshot-v1`), `status` (`Proposed`), `runId`, `packetDigest`, `proposals`; proposals sort by proposalId; statement evidence/rule IDs and conflict IDs sort ordinal, while statement and missingContext array order is preserved. Snapshot exposes immutable canonical JSON, SHA256 contentDigest and proposal count. No mutation/review/acceptance side effect occurs. Hostile HTML, Markdown, SQL, shell, URLs or instructions inside strings remain data; additional executable/tool/fetch keys are rejected. A later real UI must encode strings; this cycle supplies no renderer.

## Parser guards and failure evidence

Reject malformed/null/unknown/duplicate fields at every object level, wrong types, unsupported versions, wrong scope/run/packet, missing/foreign citations, duplicates and exceeded bounds. Fixture guards: input UTF-8 ≤64 KiB, output ≤256 KiB, depth ≤16, each string ≤4096 UTF-16 units, no unpaired surrogate, trailing JSON/comments/nonfinite/fractional numbers rejected where integers are required. These are local deterministic parser guards, not production token, budget, cost, retention or classification decisions. Metadata exposes failure codes/counts/digests only; exceptions and test reports never echo supplied payload strings. Caller strings and parsed documents cannot mutate accepted values.

## Verification and limits

Golden bytes and SHA256 oracles are authored independently of module helpers. Unit and independent composed fake-provider tests cover benign and empty output, ordering/source changes, every closed shape, invalid/foreign/cross-run citations, conflict requirements, nested duplicates, encoded hostile strings, size/depth limits and deterministic repeat validation. Dependency/architecture checks confirm no package/project/network/host integration. Full production reservation/reconciliation, retries, deletion/retention, actual authorization/revocation, provider failure/recovery, model quality, real-model injection/leakage and output rendering remain NOT VERIFIED. TP-HAS-008/012, Milestone6, SEC-PILOT-004 and G1–G9 stay open.
