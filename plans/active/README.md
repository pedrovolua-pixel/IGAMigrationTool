# Active cross-feature plans

Use this directory for approved initiatives that span multiple features or subsystems. Feature-specific implementation plans stay with their canonical feature under `/specs`.

Each plan must link its governing specifications, identify an owner and status, remain current during execution, and move to `/plans/completed` when its exit criteria are met.
