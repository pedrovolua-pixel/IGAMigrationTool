These tests use an already running guarded localhost host and a disposable owned PostgreSQL18 database. They never manage hosts, restart PostgreSQL, reset databases or contact a real provider. Follow [the Phase1B handoff](../../../docs/operations/local-phase1b-synthetic-handoff.md), [approved test plans](../../../specs/003-health-assessment/local-phase1b-closure-verification.md) and pinned Node24.21.0 toolchain.

Set `IGA_BROWSER_DEPENDENCIES` to the existing `tests/e2e/consultant-demo/node_modules` directory, or `IGA_PLAYWRIGHT_MODULE` to its installed `playwright/index.mjs`. Set `IGA_CHROMIUM` only when using an existing approved Chrome executable. `IGA_DEMO_BASE_URL` defaults to the fixed `http://127.0.0.1:5183`. `IGA_PHASE1B_E2E_OUTPUT` may select a separate evidence directory.

1. Start the dedicated Consultant host with `--pause-synthetic-worker`. Set `IGA_PHASE1B_PAUSED_HOST=1` and run `node tests/e2e/phase1b/budget-verify.mjs`. It creates an explicit empty-outcome pending run, exercises reasoned900 override and committed-response loss with exact UUID retry, and verifies immutable policy/locks and all four counters. Preserve the original log/report on failure before another execution.
2. Restart only the owned host on the same database without the pause flag. Run `node tests/e2e/phase1b/verify.mjs`. It creates and approves exact fictional outcome versions, starts the combined run, verifies automatic AI, explicit confirmation, priority/artifact/task retries, independently specified CSV bytes and current-source conflicts, protected navigation, lifecycle retirement and390/320 reflow. The report supplies its run ID.
3. Restart the same owned host/database with `--synthetic-phase1b-auditor`. Set `IGA_PHASE1B_ROLE=auditor` and `IGA_PHASE1B_AUDITOR_RUN` to the saved Consultant report's run ID; run `node tests/e2e/phase1b/verify.mjs`. It verifies denied ordinary reads/mutations, genuine scoped metadata/navigation and the exact protected-copy download with warning and320px inspection.

Each successful benign AI run charges240 from a fixed project/initiating-Consultant fixture period with hard ceiling1200. Reservation300 is checked before usage reconciliation, so a fifth benign call after960 charged is denied. Never reset counters, epoch or existing history to make a test pass. Use a separately created fresh disposable test instance when starting a new independent execution series; preserve prior evidence/databases. The paused budget test itself creates no attempt or usage.

Reports keep automated axe violations and incomplete checks separately. A zero-violation result does not verify supported manual Windows/AT/contrast/zoom acceptance. These tests do not complete UAT, full feature plans, live gates or production release.
