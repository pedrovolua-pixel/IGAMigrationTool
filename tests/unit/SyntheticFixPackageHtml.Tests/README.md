The independent Python oracle authors primitive source locks, findings, fixed templates, identity recipes, recursive ordinal JSON, full literal HTML scaffold and encoding. It never reads implementation files or captures renderer output. `python3 oracle.py --verify` checks six committed UTF-8 artifacts, including complete and empty canonical payloads, entire HTML bytes and hashes. The default mode authors these fixtures and is not part of ordinary verification.

The view uses fixed local fragment anchors and native details. Every supplied value goes through framework `HtmlEncoder.Default`; code remains encoded pre/code data. Source bindings and every guidance field are disclosed separately from packages and templates. Historical upstream unavailable statements retain their original wording and are explicitly labeled historical; current preview warnings remain separate. Finding confirmation, rejection or deferral never reviews artifacts. Empty input does not establish health. The generated document has no execution, download, copy, approval, evidence resolver or external URL action.
