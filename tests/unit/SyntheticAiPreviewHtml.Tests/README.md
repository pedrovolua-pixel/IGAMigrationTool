This dependency-free portable host verifies the settled Cycle09 offline HTML contract. The Python oracle independently authors primitive fixture values, recursive ordinal/default JSON string encoding, literal HTML scaffold/style/sections, text encoding and entire UTF-8 HTML bytes/SHA256. It never imports/calls/reads renderer source or captures renderer output. `python3 oracle.py --verify` compares three committed artifacts exactly; its default mode authors them and requires review for a golden change.

The isolated B9 worker does not own A9's factory implementation. Test-only reflection invokes the nonpublic immutable preview snapshot constructor using independently authored typed primitives and canonical JSON. That is not a production input API, proof of authorization or substitute for real composition. V9 separately composes the actual packet builder, validator, projection and renderer and runs browser checks.

The host checks complete exact source, proposal category/citation/context/conflict/uncertainty rendering, hostile text, Unicode, immutable output/detached child copies, fixed CSP/navigation and empty results that do not establish health. Corrupt canonical bytes/digests/source/typed-child bindings, malformed reflection-only graphs and UTF-8 guards receive typed payload-free denials. A reflection-only 16-proposal/64-statements-per-proposal stress graph with 3800 ASCII characters per statement has canonical bytes below 4MiB while rendered bytes exceed 4MiB; rejection checks the serialized output limit without claiming this oversized graph is a valid original Cycle08 wire input.

Run with the repository-pinned .NET SDK: locked audited restore, owned formatting verification, Release build, then the executable test host. Execution metadata binds owned source/artifacts, immutable shared source, actual binaries and transcripts. No provider, customer, database, host/UI route, storage, protected evidence resolution, action, export, approval or live renderer is involved.
