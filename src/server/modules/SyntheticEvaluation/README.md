# Synthetic evaluation policy foundation

Dependency-free internal values under the [exact local EV02 approval](../../../../specs/003-health-assessment/local-evaluation-policy-approval.md). The original [accuracy-v1 contract](../../../../specs/003-health-assessment/synthetic-evaluation-accuracy-contract.md) and canonical bytes remain unchanged.

- [Sampling v1](../../../../specs/003-health-assessment/synthetic-evaluation-sampling-v1-contract.md): complete synthetic population/version bindings, all Critical/High plus lower quota/stratum reservation, exact residual Hamilton allocation and seeded SHA256 ranks; frozen membership including unavailable items. Hard budget below required selection returns no partial sample.
- [Warnings/regression v1](../../../../specs/003-health-assessment/synthetic-evaluation-regression-v1-contract.md): separate general/desired denominator warnings below30; frozen representative compatibility and independently visible exact overall, safety-declaration, Critical/High, rejection-count and required-stratum rules. Known blocks preserve unavailable comparisons. Results are internal regression states, never pilot acceptance.
- [Reviewer fixtures v1](../../../../specs/003-health-assessment/synthetic-evaluation-reviewer-v1-contract.md): deeply captured trusted fixture assignments/qualifications/categories/conflicts; current-version eligibility with private indexed lookups. Denial carries only a typed issue and no context. Authorized insufficient context is distinct from denied review. Presentation/history grants cannot grant scored independence, protected evidence or risk authority.

All references are bounded synthetic IDs, enums closed, UTC dates explicit, snapshots detached/read-only and denials payload-free. Synthetic provider/source/approval/qualification/cause/safety declarations establish no actual authority or detection. Callers must provide stable input during capture and the current trusted fixture snapshot on each policy decision. The module has no persistence, durable uniqueness, transaction/queue cancellation, authentication adapter, audit sink, evidence resolver, real provider, UI or host registration. New corrections need a new version; these value objects cannot enforce a durable history store.

Three focused hosts and [the independent composed host](../../../../tests/integration/SyntheticEvaluationPolicy.Tests/README.md) verify selection→fixture review→explicit outcome→accuracy/warnings/regression. Exact executed source/tool/log evidence and nonauthor review are coordinator-owned in [cycle03](../../../../plans/active/local-pilot-m08-policy-implementation-cycle03.md). No external dependency, migration or runtime configuration is added. Full M08/Phase1C/TP-HAS-012/019/G1–G9 remain NOT VERIFIED.
