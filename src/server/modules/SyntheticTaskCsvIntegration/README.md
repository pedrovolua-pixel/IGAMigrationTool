# Local Phase1B CSV integration

Approved frozen engineering contract: `specs/003-health-assessment/local-phase1b-engineering-contract.md`. This adapter is fictional-only and adds no public API. Pure codec and console renderer reference no database packages.

The host obtains registry then run fences. `SyntheticPlanningTaskStore.CreateForPhase1B` accepts only the new guarded database family; old constructor guards stay unchanged. `ReadInTransactionAsync` retains genuine Consultant policies. `CaptureForExportInTransactionAsync` uses genuine Consultant/Auditor export authority and a same-transaction owning source reader, verifies all stored task/source history, and returns minimized immutable metadata. `SyntheticFixReviewStore.ReadForExportInTransactionAsync` returns metadata/vectors with its verified full Snapshot marked JsonIgnore. Artifact/task `ApplyInTransactionAsync` use original mutation authorization/history/replay logic under the caller transaction. No method opens or commits a runtime caller transaction.

`CsvExportCaptureAdapter.CreateEnvelope(capture, locks)` maps exact current source/vector and all saved task states/freshness to closed17 columns, fixed trusted localhost5183 links, and canonical input digest. `CsvCodec.Verify` compares every ordered byte/cell before hashing the actual output and creating a bound render receipt. Root must validate its exact frozen run locks before this adapter, including fixture digests; the pure codec additionally checks literal approved contracts/policy/epoch/schema.

`CsvAuditStore.InitializeAsync` is standalone setup only. It embeds `migrations/synthetic-task-csv/001-initial.sql`, verifies immutable migration digest/fingerprint and fixed data-plane binding. `AppendInTransactionAsync` appends Request → Dispatch → Render → Delivery or terminal Denial, verifies complete metadata history, exact event replay, request ordinal, scope/actor/digest bindings, and uses a request advisory lock after existing source fences. It stores only opaque metadata, fixed reason, UTC, digest and count. UTC is normalized to PostgreSQL microsecond precision before its digest. UPDATE/DELETE/TRUNCATE are denied. Transaction/audit failure returns a typed denial; caller must rollback aborted transactions and withhold bytes. No payload, cache, download token or new retention clock exists.

Host sequence: authorize/capture Request and Dispatch audit under supplied fenced transaction; commit; run renderer outside transaction; verify output; under fresh registry/run fence reauthorize and recapture the same immutable source/vector; append Render and Delivery; commit before first output byte. Source/authority conflict denies entire response and appends metadata Denial where audit remains available. `Recheck` enforces authority and full canonical capture equality; host owns category/current-resource lookup, fencing and byte boundary.

`CsvSandboxRunner` is the accepted local macOS runner, nonroot sandbox-exec with fixed pinned dotnet10.0.401 and declared four-file renderer closure, no inherited environment/credentials, denied writes/network/fork/untrusted reads, bounded stdin/stdout/stderr, ten-second wall limit,256MiB managed heap and384MiB measured RSS watchdog. The root-directory literal read enables CoreCLR startup directory lookup; child file reads remain denied. Process termination wait is bounded. Linux hosted isolated-container smoke remains separate coordinator work; local probes do not claim hosted PASS.
