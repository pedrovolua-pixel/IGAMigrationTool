## Interfaces and transaction ownership

Module dependencies: existing Npgsql10.0.3, SyntheticAiValidation, AssessmentCoverage and SyntheticSourceFence; no provider SDK/network package. Runtime methods accept the caller's NpgsqlConnection, NpgsqlTransaction and trusted AiAuthority. They validate that transaction.Connection matches the supplied connection, never open or commit a transaction and never call a provider or source-reader that opens another connection. Only InitializeAsync owns a standalone migration transaction in a guarded loopback database whose name begins iga_synthetic_phase1b_.

Coordinator obtains the outcome-registry fixed-UUID source fence before the run fence for compound/start operations. The AI module acquires the existing SyntheticRunSourceFence for its run idempotently, then the project/environment/epoch budget advisory lock for mutations, then counter rows in ordinal key order, work/attempt row, event/result/receipt. No method acquires the registry fence after a run/budget lock. No network/provider operation happens while a database transaction exists. Pure fake callback occurs after the caller commits the dispatched marker. After callback the caller opens a fresh transaction, obtains the same lock order, rechecks source/current worker eligibility and completes/checkpoints atomically. For full current reads, the coordinator holds registry→run and calls all owning modules on that supplied transaction; no independently latest join or fallback core scoring.

## Immutable records and closed shapes

AiScope fixes synthetic-customer/project/environment. AiAuthority identifies trusted actor, roles/actions, active assignment, category grants, resource state and customer/run AI policy. Fixture identity/counters come from server-side context, never model/client bodies. Worker dispatch/reconciliation and Consultant override are distinct capabilities. Published/deleted/revoked input cannot create or expose proposals. Local synthetic cancelled/terminal work may receive billing-only receipt through a separately scoped permitted reconciliation action; this grants no evidence read/promotion.

AiRunLock includes run UUID, fixed scope, coordinator profile/application/input/source/baseline digests, AI policy/provider/prompt/fixture/mapping versions/digests, fixture epoch and initiating Consultant ID. AiWork has work ID/category, immutable packet input, independent expected actual CoverageKey pairs and closed proposal→unit/evidence/rule mapping. At most16 units per work, each actual key appears exactly once in the frozen owner partition. Mapping title/impact/likelihood/root cause/severity comes from trusted fictional catalog; confidence80 and weight1. One matching ScoringInput unit exists per expected key including gaps; only Pass/Finding is health-eligible.

AiAttemptKey contains logical work key, immutable UUID, continuous ordinal1–3 and packet digest. Logical key hashes scope/run/work/full frozen packet/provider/prompt/policy/mapping identities. Per-attempt identity is part of every dispatch, lookup and receipt. Repeating exact attempt returns its exact original receipt; only known retryable no-result permits the next ordinal. An earlier known-failure receipt cannot satisfy an unknown later attempt.

AiProviderReceipt contains closed outcome KnownResponse/KnownRetryableFailure/Unknown, exact attempt identity, input/output usage integers, response when KnownResponse, output digest and immutable receipt ID. Unknown has no usage claim and keeps300 held. Known actual input0–100/output0–200 is authoritative fixture use; out-of-bound/conflicting receipt retains hold and fails integrity. Known invalid output charges actual, then commits rejection metadata/gap without rejected response payload. No partial finding commit. Same accepted receipt replay is no-charge/no-release; changed receipt UUID/attempt/payload conflicts.

Canonical input/domain/receipt bytes use closed camelCase JSON, ordinal recursively sorted properties, named enums (no numeric values), UTF-8 without BOM/newline and default System.Text.Json escaping. SHA256 lower hex binds all semantic fields; arrays have frozen semantic order, sorted unique identity sets where declared. Cycle08 packet/proposal canonicalization remains its original implementation. Text round-trips exactly; reasons max2000 UTF16, titles256, statement strings retain Cycle08 max4096. Integer revisions <=9007199254740991. Typed errors never include payload/SQL/exception text.

Immutable original packet/proposal/result canonical bytes are domain values, excluded from telemetry. Integrity verification binds continuous events and projection/receipt/source digests; schema drift denied. Append-only tables reject UPDATE/DELETE through triggers, mutation projection rows are checked against immutable events. Migration001 remains byte-for-byte unchanged.
