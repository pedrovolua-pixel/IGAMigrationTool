# Synthetic AI validation

The packet builder implements the frozen [Cycle08 fixture contract](../../../../specs/003-health-assessment/synthetic-ai-fixture-contract.md). It accepts only fictional normalized/redacted configuration fixtures in the fixed synthetic scope. This structural validation does not authenticate a caller, prove redaction or authorize real provider processing. Classification and digests grant no authority.

`SyntheticAiPacketBuilder.Build(string?)` returns a detached immutable packet or a payload-free `PacketIssue`. The input schema is closed at every object, with fixed source versions, lowercase nonempty UUIDs/digests, 1–16 unique evidence records and 1–2 unique allowlisted fixture rules. Unknown fields, comments, malformed JSON, duplicate property names, wrong types and exceeded limits fail closed. String values, including HTML, URLs, SQL, shell and embedded instructions, remain inert data.

The accepted JSON uses schema `synthetic-ai-fixture-packet-v1` and status `SyntheticDataOnly`. Object property names sort ordinal recursively; evidence sorts by evidence ID and rule IDs sort ordinal. Strings use System.Text.Json default escaping. Integer counts canonicalize as decimal integer text. The UTF-8 bytes have no BOM or trailing newline; lowercase SHA256 binds every field. Accepted strings and immutable ID arrays survive parsing-document disposal and cannot be changed by the caller.

The 64 KiB input, depth 16, 4096 UTF-16-unit string and record/count guards are deterministic local test limits. They are not production token, cost, budget, retention, normalization or classification settings. There is no provider SDK/network/tool/raw resolver, authorization system, database, host route or renderer. Existing disabled-AI assessment profiles, findings, scoring, reviews, drafts and recommendation guidance are unchanged. Proposals are never persisted or promoted. Full TP-HAS-008/012, Milestone6, SEC-PILOT-004 and live gates remain open; real policy/revocation, provider/ZDR, atomic budgets, model accuracy, semantic contradiction detection and real-model injection resistance are not verified by this module.
